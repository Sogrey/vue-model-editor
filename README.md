# 3D 模型预览工具

基于 Three.js r182 的 3D 模型在线预览工具，支持多种 3D 模型格式的加载、预览和导出。

## ✨ 功能特性

### 🎨 模型加载
- 支持格式：`.obj`, `.fbx`, `.gltf`, `.glb`, `.stl`
- 演示模型快速加载
- 拖放文件夹加载（包含纹理）
- 自动加载关联的纹理文件

### 🎥 动画支持
- 自动检测模型动画
- 播放/暂停动画
- 动画进度控制
- 播放速度调节（0.1x - 3.0x）

### 🖼️ 视角控制
- 鼠标左键拖动：旋转视角
- 鼠标右键拖动：平移模型
- 滚轮缩放：拉近/推远
- 一键重置视角

### 📸 导出功能
- 导出透明背景 PNG 图片
- 任意角度截图
- 保持模型透明度

### 🎨 界面定制
- 透明/彩色背景切换
- 自定义背景颜色
- 现代化深色主题
- 响应式设计

### 📊 模型信息
- 文件名和格式
- 文件大小
- 顶点数量
- 动画数量

### 🗂️ 场景管理
- 场景模型列表显示
- 模型显示/隐藏切换
- 模型独立删除功能
- 支持多模型同时加载

## 📖 使用说明

### 加载模型

**方式 1：选择演示模型**
- 在"演示模型"下拉框中选择预设模型
- 自动加载模型和纹理

**方式 2：上传文件**
- 点击"选择模型或文件夹"按钮
- 选择单个模型文件或整个文件夹

**方式 3：拖放**
- 将模型文件或文件夹拖放到画布区域

### 控制视角
- **左键拖动**：旋转视角
- **右键拖动**：平移模型
- **滚轮**：缩放

### 动画控制（如果模型包含动画）
- 点击"播放动画"按钮开始播放
- 使用进度滑块调整播放位置
- 调整速度滑块改变播放速度
- 点击"暂停动画"暂停播放

### 导出图片
- 调整到满意的视角
- 点击"导出透明 PNG"按钮
- 自动下载透明背景的 PNG 图片

### 场景管理
- 在"场景模型"列表查看所有加载的模型
- 点击👁️按钮显示/隐藏对应模型
- 点击🗑️按钮从场景中删除模型

## 🛠️ 技术栈

- **Vue 3** - 前端框架
- **TypeScript** - 类型安全
- **Three.js r182** - 3D 渲染引擎
- **Vite** - 构建工具

## 📝 添加演示模型

将模型文件放入 `public/models/` 目录，然后在 `src/components/ModelViewer.vue` 中的 `demoModels` 数组添加配置：

```typescript
{
  name: '模型标识名',
  label: '📦 模型显示名称',
  path: new URL('/models/文件夹名/主模型文件.gltf', import.meta.url).href
}
```

## 🔧 配置

修改 `vite.config.ts` 中的 `base` 配置可更改部署路径：

```typescript
export default defineConfig({
  base: '/your-path', // 自定义部署路径
  // ...
})
```
